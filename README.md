# LoopGrid — B2B Circular Economy & Resource Symbiosis Platform for MSMEs

**LoopGrid** is an AI-powered B2B circular economy platform built to create an operational efficiency layer for Indian MSMEs. It allows MSMEs to submit their unused resources, surplus inventory, and industrial byproducts, aggregates fragmented lots across industrial clusters, and matches them with partner enterprises that can utilize those exact materials as raw production inputs.

---

## Key Features
* **Smart Resource Onboarding:** MSMEs log unused raw materials, off-cuts, and byproducts with AI-assisted material classification.
* **Multi-MSME Lot Aggregation:** Pools small, fragmented resource volumes from multiple MSMEs into standardized bulk industrial lots.
* **AI Symbiosis Matching Engine (Powered by Google Gemini):** Matches pooled resources with nearby enterprises requiring those exact specifications as inputs.
* **Operational Efficiency & ESG Ledger:** Tracks working capital unlocked, procurement cost savings (%), waste diverted (tonnes), and verified CO2e reduction for MSME sustainability status.

---

## Tech Stack
* **Frontend:** React 19, TypeScript, Tailwind CSS, Vite
* **AI & Matching Intelligence:** Google AI Studio / Google Gemini API (`@google/genai`)
